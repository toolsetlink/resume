# 完善简历编辑页面 — 模块化排序与编辑增强

## 摘要

在现有的简历编辑器（`app/pages/workbench/[id].vue` + `SectionAccordion.vue`）基础上，增强模块管理能力：补齐「上下移动按钮」「添加模块入口（恢复已隐藏模块）」「操作指引与状态提示」三类功能。**不新增删除按钮**——现有 `t-switch` 显隐开关已承担模块移除语义（禁用=隐藏，启用=恢复）。**不在本次范围内**：移动端响应式布局、新建自定义模块类型、多实例模块、独立的删除按钮。

## 当前状态分析

### 已具备能力（基于探索）
- **模块拖拽排序**：[SectionAccordion.vue](file:///Users/songang/LinkProjects/ziyoujianli/app/components/editor/SectionAccordion.vue) 用 `vuedraggable` + `.section-drag-handle` 已实现模块卡片的拖拽排序，绑定到 `resumeStore.menuSections`，拖拽后重算 `order` 写回 store。
- **模块显隐开关**：每个模块卡片头部有 `t-switch`，调用 `toggleMenuSection` 切换 `enabled`，控制右侧预览渲染。
- **模块内条目 CRUD**：各 Panel（Experience/Education/Project/Skill/Certificate/Custom）已支持添加/删除/拖拽排序条目。
- **自动保存**：[useAutoSave.ts](file:///Users/songang/LinkProjects/ziyoujianli/app/composables/useAutoSave.ts) 防抖 1500ms 监听 store 变化写 localStorage；条目级 `useItemSaveStatus` 提供「保存中/已保存」反馈。
- **8 个内置模块**：[modules.ts](file:///Users/songang/LinkProjects/ziyoujianli/shared/config/modules.ts) 定义 basic/skills/experience/projects/education/certificates/selfEvaluation/custom，每个含 id/title/icon/enabled/order/description。
- **Store actions 齐全**：[resume.ts](file:///Users/songang/LinkProjects/ziyoujianli/app/stores/resume.ts) 已有 `updateMenuSections` / `toggleMenuSection` / `setActiveSection` / `ensureMenuSections`（旧数据迁移）。

### 现有缺陷（本次要解决）
1. **无上下移动按钮**：仅拖拽，无显式上下移动交互，不够直观。
2. **无添加模块入口**：已禁用的模块（`enabled=false`）在折叠面板中仍可见但无「重新启用」入口；用户无法从 UI 上「添加」模块，只能依赖初始 `MODULE_CONFIGS` 的默认 `enabled`。
3. **缺操作指引**：无首次使用引导、无空状态提示、无拖拽提示文案、无模块库入口说明。

### 不在本次范围（基于用户确认）
- **不新增删除按钮**：现有 `t-switch` 显隐开关已承担模块移除语义，禁用=隐藏（数据保留），启用=恢复。无需独立的删除按钮。
- **移动端布局**：本次不做。
- **新建自定义模块类型 / 多实例模块**：本次不做。

## 设计决策

| 决策点 | 选择 | 影响 |
|---|---|---|
| 模块添加 | 仅恢复内置模块 | 不新增模块类型，只在「模块库」面板列出 `enabled=false` 的内置模块供重新启用 |
| 模块移除 | 复用现有 `t-switch` | 不新增删除按钮；禁用开关=隐藏模块（数据保留，可从模块库恢复） |
| 移动端 | 本次不做 | 工作台保持桌面端 Splitpanes 双栏 |
| 拖拽柄 | 仅保留一个 | 现有 `.section-drag-handle` 已是唯一拖拽柄，保持不变 |
| 上下移动边界 | 首模块禁用上移，末模块禁用下移 | 通过 `disabled` 属性禁用按钮，不循环移动 |

## 提议改动

### 1. 扩展 Store Actions（[app/stores/resume.ts](file:///Users/songang/LinkProjects/ziyoujianli/app/stores/resume.ts)）

新增 2 个 actions，**不改动现有 actions**（复用现有 `toggleMenuSection` 承担模块显隐/移除语义）：

```typescript
// 移动模块顺序（up/down）
// resumeId: 简历 ID；sectionId: 模块 ID；direction: 'up' | 'down'
moveMenuSection(resumeId: string, sectionId: string, direction: 'up' | 'down') {
  const r = this.resumes.find((r) => r.id === resumeId)
  if (!r) return
  // 按 order 排序得到当前顺序
  const sorted = [...r.menuSections].sort((a, b) => a.order - b.order)
  const idx = sorted.findIndex((s) => s.id === sectionId)
  if (idx === -1) return
  const targetIdx = direction === 'up' ? idx - 1 : idx + 1
  // 边界检查：首模块上移 / 末模块下移直接返回（按钮已 disabled，此处为兜底）
  if (targetIdx < 0 || targetIdx >= sorted.length) return
  // 交换位置
  ;[sorted[idx], sorted[targetIdx]] = [sorted[targetIdx], sorted[idx]]
  // 归一化 order 并写回
  r.menuSections = sorted.map((s, i) => ({ ...s, order: i }))
  r.updatedAt = new Date().toISOString()
}

// 启用模块（从模块库恢复已隐藏模块）
enableMenuSection(resumeId: string, sectionId: string) {
  const r = this.resumes.find((r) => r.id === resumeId)
  if (!r) return
  const section = r.menuSections.find((s) => s.id === sectionId)
  if (!section) return
  if (section.enabled) return  // 已启用则无操作
  section.enabled = true
  r.updatedAt = new Date().toISOString()
}
```

> 说明：模块「删除」复用现有 `toggleMenuSection(resumeId, sectionId)`，将 `enabled` 置为 `false` 即可，数据保留，可从模块库恢复。无需新增 `removeMenuSection`。

### 2. 增强 SectionAccordion 组件（[app/components/editor/SectionAccordion.vue](file:///Users/songang/LinkProjects/ziyoujianli/app/components/editor/SectionAccordion.vue)）

在每个模块卡片的标题行增加「上移 / 下移」按钮，**保留唯一的拖拽柄**和现有的显隐开关，**不新增删除按钮**：

```
[拖拽柄] [图标] [标题]  [上移] [下移] [可见性开关] [展开箭头]
```

具体改动：
- **保留唯一拖拽柄**：现有 `.section-drag-handle`（lucide `GripVertical`）是唯一的拖拽柄，保持不变。不新增其他拖拽元素，确保拖拽功能不受影响、交互体验一致。
- **新增上移/下移按钮**：lucide `ChevronUp` / `ChevronDown`，调用 `resumeStore.moveMenuSection(resumeId, sectionId, 'up' | 'down')`。
  - **首模块禁用上移**：通过 `:disabled` 属性禁用按钮，鼠标样式变为 `not-allowed`，颜色变浅。
  - **末模块禁用下移**：同上。
  - 计算「首/末」时基于按 `order` 排序后的 `menuSections` 数组，当前模块在索引 0 则为首模块，在 `length - 1` 则为末模块。
- **保留显隐开关**：现有 `t-switch` 不变，控制 `enabled`。开关关闭=模块从预览隐藏（数据保留）；开关打开=模块恢复显示。这已承担「移除模块」的语义，无需额外删除按钮。
- **不新增删除按钮**：移除原计划中的 `Trash2` 删除按钮及相关二次确认逻辑。
- **拖拽柄 tooltip 升级**：将拖拽柄的原生 `title="拖动排序"` 升级为 TDesign `t-tooltip`，文案「拖动排序」。
- **上下移动按钮 tooltip**：`t-tooltip` content 分别为「上移」「下移」。
- **按钮组布局**：操作按钮（上移/下移/开关）紧凑排列在标题右侧，展开箭头保持在最右。使用 `flex items-center gap-1` 布局。

## 假设与决策

1. **决策**：上移/下移按钮在首/末位置禁用（`disabled`），不循环移动。
2. **决策**：模块库对话框用 `t-dialog`（轻量）而非 `t-drawer`，因模块列表较短。
3. **决策**：引导提示条仅在首次显示，用 localStorage 标记，避免打扰老用户。
4. **决策**：模块「移除」复用现有 `t-switch` 显隐开关，不新增删除按钮。关闭开关=隐藏（数据保留），可从模块库恢复。
5. **决策**：保留唯一的拖拽柄（`.section-drag-handle`），不新增其他拖拽元素，确保拖拽功能不受影响。
6. **决策**：不在本次实现移动端响应式布局（用户明确确认）。

### 功能验证
1. **拖拽排序**：拖动模块卡片（仅拖拽柄可拖），顺序变化且右侧预览实时更新，刷新页面后顺序保留。
