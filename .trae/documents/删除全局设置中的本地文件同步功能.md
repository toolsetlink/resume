## Assumptions & Decisions

1. **完全删除 vs 仅隐藏**: 用户说「删除掉……功能」，理解为完全移除（含 composable、测试、i18n），而非仅从抽屉中隐藏。这符合避免遗留死代码的最佳实践。
2. **落地页 `sync` 特性保留**: `FeaturesSection.vue` 的 `sync` 卡片标题是「本地同步/Local Storage」，描述的是 localStorage 隐私保护，与 File System Access API 双向同步是两个概念。该卡片宣传的隐私特性仍由 Pinia persist 提供，保留。
3. **localStorage 持久化保留**: Pinia persist 插件自动写入 localStorage 的逻辑不动，确保应用核心数据持久化能力不受影响。
4. **不手动改 .nuxt 生成文件**: `components.d.ts` / `imports.d.ts` 会在执行 `nuxt prepare`（或 `pnpm postinstall`）时自动刷新，手动编辑会被覆盖。
5. **不删除落地页 i18n `landing.features.items.sync`**: 命名空间路径不同，属于落地页特性介绍。
